# IncrementalDiablo

## 제품 약속

오프라인 PC 인크리멘탈 액션 RPG다. 플레이어는 자동 전선으로 기본 자원을 얻고, 직접 조작하는 방 단위 원정에서 위험을 감수해 장비와 재료를 얻으며, 영웅과 방어를 함께 성장시킨다.

```text
자동 전선 → 원정 계약 선택 → 랜덤 방 전투 → 귀환 또는 심층 선택
→ 전리품/제작 → 영웅과 방어 성장 → 다음 원정
```

## 최종 던전 형태

- 던전은 고정된 한 장의 맵이나 끝없는 같은 방이 아니다. 원정마다 시드와 깊이로 선택된 방 템플릿을 차례로 불러오는 방 단위 원정이다.
- 각 방은 손으로 만든 템플릿이며, 적·오브젝트·장애물·조우는 유효 앵커 안에서 시드 기반으로 배치한다. 입구와 두 출구의 이동 가능 경로는 항상 보장한다.
- 방을 정리하면 귀환 포탈과 심층 출구가 열린다. 포탈은 현재 원정의 미확정 보상을 확정하고 거점으로 돌려보내며, 심층 출구는 더 높은 위험·보상으로 다음 방을 불러온다.
- 사망하면 현재 원정의 미확정 보상만 잃고 이미 확정한 장비·재료·전선 진행은 보존한다. 무한 파밍은 심층 진행과 새 원정의 반복으로 만든다.

## 고정 원칙

- 전선은 자동 방어다. 개별 유닛 명령, 생산 큐, 자유 타워 배치, 수동 웨이브, RTS 경제는 만들지 않는다.
- 던전은 직접 조작의 위험과 대응이 있어야 한다. 색상·수치·HUD 문구만 다른 적은 콘텐츠가 아니다.
- 장비와 제작은 중복, 분해, 재료, 로드아웃, 방어 연계를 통해 장기 선택을 만든다.
- 모든 큰 시스템은 보상 또는 실패, 저장 의도, 재사용 규칙, 검증 경로를 가진다.

## 현재 제작 기준

현재 P0는 `ProductionDocs/08_ProductionRoadmap.md`의 E3-D다. 고정된 두 방 씬을 만드는 일이 아니라, 포탈 선택형 랜덤 방 원정의 데이터·로딩·저장 기반을 만든다.

이 문서와 `03`~`08`만 현재 제작 기준이다. 과거 MVP, HUD QA, 카메라 검토, 이력 문서는 현재 작업 근거가 아니다.
