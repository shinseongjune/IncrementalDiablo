# Production Roadmap

## 작업 선택 규칙

매일 가장 앞선 `P0`만 진행한다. 문서, HUD 문구, 하네스, 회귀 체크는 그 P0를 직접 막거나 깨진 경우에만 다룬다. 완료된 작업을 다시 열어 작은 개선을 만들지 않는다.

## 최종 제품 방향

던전은 시드 기반의 방 단위 원정이다. 방을 정리할 때마다 귀환 포탈로 미확정 보상을 확정하거나 심층 출구로 다음 랜덤 방을 불러온다. 무한 파밍은 고정 맵 반복이 아니라 심층 진행과 새 원정의 반복으로 만든다.

## 현재 P0 — E3-D 랜덤 방 원정 기반

기존 `DungeonTraversalController`·`DungeonTraversalTrigger`와 방별 스폰 위치는 같은 씬에서 방 진입·전투·귀환을 증명한 전환용 기반이다. `Gameplay`에 고정 두 방을 배치하는 일은 더 이상 완료 기준이 아니다.

- [x] 방 진입, 전투 시작, 방별 적 스폰, 보상·귀환의 기존 권한을 분리했다.
- [x] 최종 원정의 포탈 선택, 심층 진행, 시드 배치, 실패·보상·저장 계약을 확정했다.
- [x] `DungeonRunPlan`으로 원정 시드, 깊이, 방 템플릿, 배치 계획, 미확정 보상을 모델링하고 저장 마이그레이션을 만들었다.
- [x] `DungeonRoomTemplate` 카탈로그와 `DungeonRoomLoader`로 현재 방 하나만 로드·해제한다. 템플릿 ID는 시드로 한 번 선택해 저장하고, 없는 ID는 다른 방으로 대체하지 않는다.
- [x] `CombatRoom`은 현재 `DungeonRunPlan` 템플릿이 로드된 뒤에만 시작하고, `EnemySpawner`는 그 템플릿의 적 앵커에서만 생성하게 연결했다.
- [x] 방 정리 뒤 `ReturnPortal`/`DeeperExit`를 열고, 귀환은 보상을 확정해 거점으로 돌려보내며 심층 선택은 미확정 보상을 유지한 채 다음 시드 방을 로드한다. 이 선택 상태도 v8 저장으로 복원한다.
- [x] 중립적인 `crypt_a`/`crypt_b` additive 템플릿과 각 방 NavMesh, `Gameplay/DungeonRoot` 카탈로그, Build Settings를 연결했다.
- [ ] v2 월드 체크포인트는 `AccountSnapshot` + `DefenseWorldSnapshot` + 열린 경우의 `DungeonWorldSnapshot`을 한 세대/해시 봉투에 저장한다. 안정 tick에서만 캡처하고, 주/백업 중 가장 높은 정상 세대를 복원한다. 방어 건물·전 유닛과 열린 던전의 영웅/적 위치·체력·행동이 실제로 이어지는 Play Mode 증명이 남아야 한다. v1/v9 파일은 읽거나 변환하지 않는다.
- [ ] Play Mode에서 `귀환 확정 → 새 원정`, `심층 → 다음 방`, `사망 → 미확정 보상 폐기`, `저장/불러오기 복원`, 북쪽 포탈이 보이는 카메라 프레이밍을 확인한다.

## 첫 버티컬 슬라이스

| 순서 | 작업 | 완료 기준 |
| --- | --- | --- |
| E3-D | 현재 P0 — 랜덤 방 원정 | 방 단위 로딩, 포탈/심층 선택, 시드 배치, 저장이 한 원정에서 이어진다. |
| E3-E | 완성 세션 | 전선 → 계약 → 원정 → 보상/제작 → 방어 투자 → 저장/불러오기가 한 세션에서 이어진다. |

## 게임 완성 단계

| 단계 | 목표 |
| --- | --- |
| F | 재사용 가능한 방 템플릿, 적/보스 행동, 모델/애니메이션/VFX/SFX, 아이템 빌드·제작 소모처, 방어 로드아웃을 만든다. |
| G | 다층 심층 진행, 엔드게임 원정 반복, 경제 안정성, 저장 호환, 성능을 실제 콘텐츠와 함께 만든다. |
| H | 접근성·입력·정식 설정, 빌드/QA/배포 준비를 끝낸다. |

## 완료 기준

- 버티컬 슬라이스: 서로 다른 방 템플릿, 시드 배치, 귀환/심층 선택, 보상·실패·저장이 연결된 플레이 가능한 원정.
- Early Access: 여러 방·테마·적·보스 조합, 장기 소모처, 막히지 않는 진행, 저장/성능/빌드 품질.
- 이후 확장: 장시간 플레이는 콘텐츠 수작업 양이 아니라 방 템플릿, 배치 규칙, 드롭 규칙, 소모처, 로드아웃의 조합으로 만든다.
