# Production Roadmap

## 작업 선택 규칙

매일 가장 앞선 `P0`만 진행한다. 문서, HUD 문구, 하네스, 회귀 체크는 그 P0를 직접 막거나 깨진 경우에만 다룬다. 완료된 작업을 다시 열어 작은 개선을 만들지 않는다.

## 현재 P0 — E3-C 적 행동과 텔레그래프 (진행 중)

완료: 첫 근접 적은 0.65초 선행 중 공격 범위 링을 표시하고, 실행 순간 기존 `CombatDriver`/`Health` 경로로 사거리를 다시 확인한다. 보상·저장·전투 수치는 바꾸지 않는다.

다음 확인 체크리스트:

- [ ] `Gameplay`에서 링 신호가 공격 범위와 읽기 쉽게 겹치는지 확인한다. 필요하면 `EnemyAttackTelegraph`의 높이·두께·색만 조정한다.
- [ ] 링 밖으로 이탈해 피해가 취소되는지 확인한다.
- [ ] 링 안에 남아 한 번만 피격되고, 적 처치 뒤 기존 보상으로 이어지는지 확인한다.

E3-B 완료: `HeroDefault`와 `OrcPADefault` 시각 Prefab을 기존 `Player`/`PF_DungeonEnemy_Melee` 루트의 `Model` 자식으로 연결했고, 공통 `Combat` 상태기와 Hero/Orc Override Controller를 적용했다. 사용자 Play Mode에서 두 전투 주체의 Idle, Move, Attack, Hit, Death를 확인했다. 이후 모델·Animator 연결은 회귀 전용이다.

## 게임 완성 단계

| 단계 | 목표 |
| --- | --- |
| F | 재사용 가능한 모델/애니메이션/VFX/SFX 프리팹, 모듈형 맵, 적/보스 행동, 아이템 빌드·제작 소모처, 방어 로드아웃을 만든다. |
| G | 다층 진행, 엔드게임 반복, 경제 안정성, 저장 호환, 성능을 실제 콘텐츠와 함께 만든다. |
| H | 접근성·입력·정식 설정, 빌드/QA/배포 준비를 끝낸다. |

## 완료 기준

- 버티컬 슬라이스: 실제 모델/전투/맵/보상이 연결된 플레이 가능한 세션.
- Early Access: 여러 콘텐츠 템플릿, 장기 소모처, 막히지 않는 진행, 저장/성능/빌드 품질.
- 이후 확장: 900시간 목표는 콘텐츠 수작업이 아니라 템플릿, 드롭 규칙, 소모처, 로드아웃의 조합으로 만든다.
