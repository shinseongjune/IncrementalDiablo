# Items, Crafting, And Economy

## 목적

전리품은 영웅 전투와 자동 방어의 다음 선택을 만든다. 인벤토리를 채우거나 한 번 장비를 맞춘 뒤 멈추는 보상이 아니다.

## 원정 보상 계약

- 방 정리로 얻는 장비·재료는 현재 원정의 미확정 보상에 쌓인다. 귀환 포탈을 사용했을 때만 장기 인벤토리와 방어 자원으로 확정된다.
- 심층 출구는 다음 방의 위협과 보상 계획을 올린다. 사망하면 현재 원정의 미확정 보상만 폐기하며, 기존 확정 보상은 보존한다.
- 모든 보상 수량과 확률은 `per-room-clear`, `per-run-return`, `per-kill`처럼 분모를 명시한다. 아직 정하지 않은 심층 보상 수치는 임의로 채우지 않는다.

## 장기 선택

- 아이템 정의/인스턴스, 장비 슬롯, 인벤토리, 분해, 중복 변환, 희귀 옵션 재굴림은 현재 저장 모델을 사용한다.
- 장비 빌드와 방어 소비처는 서로 다른 원정 계약·심층 선택이 생기게 해야 한다.
- 제작은 재굴림의 종점이 아니라 다음 원정의 위험을 감수할 이유를 만든다.

## 변경 규칙

- 드롭률, 가격, 재료 수량, 제작 비용을 바꾸기 전에는 읽기 전용 D2 참고 자료와 해당 밸런스 내보내기를 확인한다.
- 수치 변경은 분모와 저장 데이터 영향 검증을 함께 갱신한다.
- UI 문구만 바꾸어 실제 보상 선택을 대신하지 않는다.
