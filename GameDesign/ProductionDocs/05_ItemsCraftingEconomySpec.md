# Items, Crafting, And Economy

## 목적

전리품은 영웅 전투와 자동 방어의 다음 선택을 만든다. 인벤토리를 채우는 보상이나 한 번 장비를 맞춘 뒤 멈추는 시스템이 아니다.

## 현재 계약

- 아이템 정의/인스턴스, 장비 슬롯, 인벤토리, 보상, 분해, 중복 변환, 희귀 옵션 재굴림은 현재 저장 모델을 사용한다.
- 보상 수량과 확률은 항상 `per-clear`, `per-kill`처럼 분모를 명시한다.
- 중복 희귀, 낮은 가치 드롭, 인벤토리 비대화는 분해, 재료 변환, 필터, 자동 분해, 제작 소모처로 해결한다.

## 다음 제품 요구

1. 서로 다른 영웅 빌드와 방어 활용처를 만든다.
2. 제작에는 재굴림 외의 잠금, 강화, 변환 또는 장기 소모처를 추가한다.
3. 장비가 완성된 뒤에도 재료, 수집, 로드아웃, 방어 투자로 다음 목표가 남는다.

## 경제 변경 규칙

- 드롭, 희귀도, 재료 수익, 제작 비용을 바꾸기 전 D2 참고 자료를 읽되 거래·래더·멀티플레이 경제는 가져오지 않는다.
- 수치 변경에는 데이터 표와 관련 내보내기 검증을 추가 또는 갱신한다.
- UI 비교 문구는 실제 선택을 설명할 때만 바꾼다. 문구 자체는 작업 항목이 아니다.
