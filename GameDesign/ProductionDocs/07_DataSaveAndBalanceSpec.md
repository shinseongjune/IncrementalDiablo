# Data, Save, And Balance

## 권한

- `DefenseRuntimeState`는 전선, 벽, 압력, 자원, 진행의 저장 권한이다.
- 던전 실행 상태는 깊이, 계약, 조우, 보상 대기를 저장한다.
- 아이템/장비/인벤토리와 UI 설정은 기존 저장 스키마와 마이그레이션 경로를 사용한다.
- 시각 배우, Animator, HUD는 저장 권한을 만들지 않는다.

## 변경 규칙

- 저장 필드를 추가하면 기본값, 이전 저장 마이그레이션, 불러오기 실패 처리를 함께 정의한다.
- 수치 변경은 한 가지 분모와 데이터 내보내기 경로를 가진다.
- 깊이, 전선, 적, 보상은 손제작 레벨 표 대신 밴드/공식/템플릿으로 확장한다.
- 수치 상한은 안전 장치일 뿐 콘텐츠 목표가 아니다.

## 검증

- 저장 구조 변경: 새 저장과 기존 저장 불러오기.
- 수치 모델 변경: 관련 내보내기 스크립트.
- 런타임 계약 변경: 빌드와 최소 하네스.
