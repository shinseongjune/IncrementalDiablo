# Core Loop And Player Flows

작성일: 2026-05-03
문서 목적: 플레이어가 실제로 누르는 것과 화면 흐름 정의

## 1. 최상위 루프

```text
지상 전선 확인
→ 지속 보상 확인
→ Hold/Push 판단
→ 방어 강화 또는 제작 준비
→ 지하 던전 원정
→ 장비/재료 획득
→ 장비 장착/제작/강화
→ 더 높은 Frontline Level과 던전에 도전
```

이 루프가 게임의 중심이다.

## 2. 메인 화면 흐름

MVP의 메인 화면은 4개 탭으로 구성한다.

```text
[지상 전선] [지하 던전] [장비/제작] [영웅/성장]
```

### 지상 전선 탭

플레이어가 보는 것:

- 현재 Frontline Level
- 현재 Mode: Hold 또는 Push
- Enemy Pressure
- Frontline Progress
- 성벽 체력
- 포탑 레벨
- 병력 레벨
- Gold/Scrap
- 수리 필요 여부

플레이어가 누르는 것:

- `전선 시작`
- `Hold/Push 전환`
- `성벽 강화`
- `포탑 강화`
- `병력 훈련`
- `수리`

게임 반응:

- 적 압박이 계속 생성된다.
- 포탑과 병력이 압박을 자동으로 막는다.
- 버티는 동안 Gold/Scrap이 쌓인다.
- Hold는 안정 파밍을 제공한다.
- Push는 압박이 커지는 대신 다음 Frontline Level 진행도가 오른다.
- 성벽 체력 또는 압박 한계가 무너지면 전선이 돌파된다.

### 지하 던전 탭

플레이어가 보는 것:

- 선택 가능한 던전
- 권장 전투력
- 예상 주요 보상
- 자동 원정 가능 여부
- 직접 조작 권장 여부
- 영웅 현재 상태

플레이어가 누르는 것:

- `던전 선택`
- `자동 원정 시작`
- `직접 입장`
- `귀환`

게임 반응:

- 자동 원정은 결과 로그와 보상을 반환한다.
- 직접 입장은 디아블로식 조작 전투 씬으로 들어간다.
- 실패하면 미확정 보상 일부를 잃고 경험치 일부가 손실된다.

### 장비/제작 탭

플레이어가 보는 것:

- 인벤토리
- 장착 장비
- 제작 가능한 베이스
- 강화 비용
- 분해 결과
- 변형 가능 여부

플레이어가 누르는 것:

- `장착`
- `제작`
- `강화`
- `분해`
- `옵션 변형`

게임 반응:

- 장비 스탯이 영웅 전투력에 반영된다.
- 일부 제작 결과는 지상 방어 보너스에도 반영된다.
- 분해하면 기본/희귀 재료를 회수한다.

## 3. 첫 30분 플레이 플로우

### 0-5분: 지속 전선 이해

1. 게임 시작.
2. 지상 전선 탭이 먼저 열린다.
3. 전선 전투가 자동으로 시작된다.
4. Enemy Pressure가 계속 움직인다.
5. 방어력이 압박을 막으면 Gold/Scrap이 쌓인다.
6. 플레이어가 `포탑 강화` 또는 `성벽 강화`를 누른다.

완료 감각:

```text
전선이 계속 싸우고 있고, 버티는 동안 돈이 쌓인다.
```

### 5-12분: 첫 Push 판단

1. Hold 상태에서 안정적으로 보상이 쌓인다.
2. 플레이어가 Push를 켠다.
3. Enemy Pressure가 더 강해진다.
4. 압박을 버티면 Frontline Progress가 찬다.
5. 진행도가 차면 Frontline Level이 오른다.

완료 감각:

```text
안정 파밍과 위험한 단계 상승을 내가 고른다.
```

### 12-20분: 지하 던전 진입

1. 기본 재료와 금화가 모인다.
2. 첫 무기 베이스를 제작한다.
3. 지하 던전 탭이 열린다.
4. 영웅이 첫 던전에 입장한다.
5. 일반 적과 싸운다.
6. 보스 또는 엘리트 적을 처치한다.
7. 장비/희귀 재료를 얻는다.

완료 감각:

```text
지상에서 번 돈으로 던전에 들어가고, 던전에서 진짜 장비를 얻는다.
```

### 20-30분: 루프 연결 확인

1. 획득 장비를 장착한다.
2. 희귀 재료로 포탑 또는 장비를 강화한다.
3. 다시 지상 전선으로 돌아간다.
4. 이전에 버티지 못했던 압박을 버틴다.
5. Push로 다음 Frontline Level을 올린다.

완료 감각:

```text
던전 보상이 지상 성장에 영향을 준다.
```

## 4. 실패 플로우

### 지상 전선 돌파

```text
Enemy Pressure 누적 또는 성벽 체력 0
→ 전선 돌파
→ 성벽 손상
→ 지속 보상 중단 또는 대폭 감소
→ 수리/강화
→ Hold 또는 Push로 재시작
```

지상 실패는 게임오버가 아니다. 플레이어에게 다음 행동을 알려주는 신호다.

### 던전 실패

```text
던전 실패
→ 미확정 아이템 손실
→ 경험치 일부 손실
→ 장비 내구도 손상
→ 성채 복귀
→ 장비/방어 강화 후 재도전
```

던전 실패는 디아블로식 위험을 담당한다. 단, 핵심 장비 영구 삭제는 MVP에서 제외한다.

## 5. 자동 진행 플로우

### 지상 지속 진행

```text
전선 시작
→ Hold로 안정 파밍
→ Push로 다음 단계 진행
→ 압박이 강하면 손상
→ 돌파 시 진행 정지
```

돌파 시 진행을 멈추는 이유:

- 플레이어가 손상 상태를 알아야 한다.
- 무한 실패 반복으로 재화가 낭비되는 느낌을 줄인다.

### 지하 자동 원정

MVP에서는 던전 자동 원정을 단순 결과 계산으로 처리해도 된다.

```text
자동 원정 시작
→ 영웅 전투력과 던전 난이도 비교
→ 방 단위 전투 로그 생성
→ 성공/실패 결정
→ 보상 반환
```

직접 조작 던전은 별도 화면/카메라/방 프리팹 또는 나중의 additive 시각 레이어로 구현할 수 있다. 단, 지상 전선 런타임을 언로드하지 않는다. 던전을 조작하는 동안에도 지상 전선은 숫자 시뮬레이션과 HUD 상태로 계속 살아 있어야 한다.

## 6. UI 상태 규칙

모든 탭은 다음 상태를 명확히 보여야 한다.

| 상태 | 표시 |
| --- | --- |
| 할 일 있음 | 버튼 강조, 짧은 문구 |
| 재화 부족 | 필요한 재화와 부족량 표시 |
| 손상 있음 | 수리 필요 배지 |
| 새 보상 있음 | 획득량 증가 표시 |
| 막힘 | 현재 막힌 Frontline Level/던전과 추천 행동 표시 |

추천 행동 예시:

```text
Frontline Lv.12 돌파됨
추천: 성벽 수리, 포탑 Lv.4 강화, Hold로 재시작
```

## 7. 구현 완료 기준

이 문서 기준 구현 완료:

- 플레이어가 4개 탭을 오갈 수 있다.
- 지상 전선이 끊기지 않고 계속 돌아간다.
- Hold/Push 차이가 보인다.
- 지상 보상이 제작/강화에 쓰인다.
- 던전 보상이 장비에 반영된다.
- 강화 후 이전 막힘을 넘는 경험이 가능하다.
